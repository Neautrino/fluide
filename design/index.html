Design system 01 · primary

Fluide
Studio

A drafting table for your money. By day: white paper, 1px black ink, pastel account tiles — the ofsp_ce look. By night: the same drawing as a negative: neutral charcoal paper, one light ink, the same corners and outlines, and the same pastel tiles, calmed. Charts are drawn like a studio would draw them: one ink colour, one highlight, and hatching for anything that isn't final yet.

Light ← #8 ofsp_ce. White canvas, wide bold grotesk, 1px black outlines, peach / periwinkle / sage-grey / dusty-pink tiles, black bars with one pill-labelled bar, split-ring icon buttons.

Dark = light as a negative. Neutral charcoal #222224 with no hue cast, one light ink #ececea for text, outlines, the lead series, hatch and the one emphasis block. The same four tile hues at one calmer lightness, the same 4/8/12/20 radii, split-ring icon buttons.

Charts ← #6, #7, #3, #1. One hatched highlight bar, confidence-style dotted "typical" line, tooltip pills, donut with a centre figure, goal bar with a marker, date chips on bills.

1

Ink is the chart

Every chart has one lead series in chart-1 (black by day, the light ink by night — never green, so spending never reads as "good"). Everything else is muted. One highlight per chart, named in a pill.

2

Hatched means not final

Unreviewed spend, possible transfers and expected bills are drawn hatched or dashed, never solid. Solid ink is only for money that has actually settled and been categorised.

3

Every number says when

Each headline figure carries its freshness stamp and its currency. ₹, € and $ sit side by side, never added together. Red appears only when something is broken — never for ordinary spending.

02

Colour

Light is sampled from the reference pixels; dark is derived from it as a negative. Both themes are shown at once; ratios are computed live from tokens.css (WCAG 2.x, AA ≥ 4.5 for text).

03

Type

Archivo drawn at 125% width for display (closest free match to #8's wide grotesk), Plus Jakarta Sans for UI (tabular figures, ₹ glyph), Geist Mono for data and IDs. All three carry ₹ and a true minus −.

The one-highlight rule

✓ Do
Muted bars, one bar in chart-1, the value in an inverse pill. The unreviewed part of September is hatched.
✕ Don't
Rainbow bars, no pill: nothing to read first. Red for "high" spend: spending isn't an error.

Hatch vocabulary

provisional (unreviewed / possible transfer) expected (projection) typical (your median) settled
